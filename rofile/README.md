# ChemAI Atlas

**Discover AI tools, models, agents, MCP servers, and open-source projects for chemistry.**

ChemAI Atlas is an open directory for discovering AI resources across chemistry, cheminformatics, molecular modeling, drug discovery, materials science, and related scientific fields.

🌐 **Website:** [chemaiatlas.com](https://chemaiatlas.com)

---

## Explore Chemistry AI

ChemAI Atlas organizes chemistry-focused AI resources into practical categories:

- 🤖 **AI Models** — Foundation models, molecular models, property prediction models, and chemistry-specific AI
- 🧪 **AI Tools** — Web tools and applications powered by artificial intelligence
- 🤝 **AI Agents** — Autonomous and semi-autonomous agents for scientific workflows
- 🔌 **MCP Servers** — Model Context Protocol servers for chemistry and scientific applications
- 💻 **Open Source** — Open-source chemistry AI projects, libraries, frameworks, and platforms
- 📚 **Guides** — Practical guides for using AI in chemistry and scientific research

---

## What We're Building

Our goal is to make it easier for students, researchers, developers, and industry professionals to discover useful AI resources for chemistry.

Instead of searching across GitHub, research papers, product websites, and social platforms separately, ChemAI Atlas brings these resources together in one structured directory.

### Main Areas

| Category | Examples |
| --- | --- |
| AI Models | Molecular generation, property prediction, retrosynthesis |
| AI Tools | Structure analysis, prediction, literature research |
| AI Agents | Research assistants, workflow automation |
| MCP Servers | Chemistry databases, scientific tools, molecular data |
| Open Source | Libraries, frameworks, research code |
| Guides | Tutorials, comparisons, practical workflows |
