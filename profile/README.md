# ChemAI Atlas

Discover, learn, and build with AI for chemistry.

ChemAI Atlas is a curated platform for exploring and using artificial intelligence across chemistry, cheminformatics, molecular modeling, drug discovery, materials science, and related scientific fields.

🌐 Website: https://chemaiatlas.com/

## Featured Repositories

### [awesome-chemistry-ai](https://github.com/chemaiatlas/awesome-chemistry-ai)

A curated list of chemistry AI models, agents, MCP servers, skills, tools, datasets, APIs, and open-source projects.

**Use it to discover what exists in the chemistry AI ecosystem.**

### [chemistry-ai-recipes](https://github.com/chemaiatlas/chemistry-ai-recipes)

Curated and practical AI workflows for chemistry, combining models, agents, MCP servers, APIs, and scientific software into reproducible setups.

**Use it to learn what works together and how to set it up.**

## ChemAI Atlas Ecosystem

ChemAI Atlas is organized around three layers:

**Discover**  
Explore models, agents, MCP servers, skills, open-source projects, and other chemistry AI resources.

**Learn**  
Read practical guides explaining chemistry AI concepts, tools, and workflows.

**Build**  
Use ChemAI Recipes to find curated tool combinations and step-by-step setups for real chemistry tasks.
